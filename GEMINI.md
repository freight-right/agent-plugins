# Freight Right

This extension connects Gemini CLI to the Freight Right MCP connector at
`https://mcp.freightright.com/mcp` over streamable HTTP. Sign in with
`/mcp auth freightright` and a Shipment Manager account. There is no API key.

The tool timeout is 60 seconds. A price check asks carriers live and can take that long.

The skills shipped with this extension are the workflow. The connector documentation is at
<https://developers.freightright.com>.
