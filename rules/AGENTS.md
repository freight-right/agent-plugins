# Freight Right

This plugin connects Antigravity to the Freight Right MCP connector at
`https://mcp.freightright.com/mcp` over streamable HTTP. When the server connects, sign in
with a Shipment Manager account in the browser. There is no API key.

A price check asks carriers live and can take up to a minute.

The skills shipped with this plugin are the workflow. The connector documentation is at
<https://developers.freightright.com>.
